# healthcare-cyber-threat-intelligence-and-risk-analytics
To Understand healthcare/biotech organization about - What type of cyberattack are affecting healthcare companies, which vulnerabilities are actively exploited, which attack types are most common, which assets or system are at high risk, what security controls should be priotized, how to reduce ransomware, phishing, data breach, vulnerability risk.

Dataset used:
Dataset Source: U.S. Department of Health and Human Services, Office for Civil Rights Breach Portal, 
dataset contain reported case where healthcare related organization had breach of protected health information.
Dataset contain: Healthcare breaches 500 or more individuals

Why this Dataset is useful?
To build healthcare cyber threat intelligence and risk analytics we can analyze:
1. How many Healthcare breaches happened?
2. Which breach type is more common?
3. How many people were affected?
4. Which Healthcare entity types are more exposed?
5. Whether breach happen through email, network server, electronic medical records, laptops or paper record?
6. Which case are high risk based on affected individuals and breach type?

The project won't stop attack but it will help organization understand cyber risk, priotize defense, make better security decisions
Project can help answer to:
1. What kind of cyber incidents are happening in Healthcare?
2. Which breach types affect the highest number of people?
3. Are Hacking/IT incident increasing?
4. Which system are more commonly involved - email, network, EMR, Laptop, or Paper record?
5. Which risk should a healthcare/biotech organization fix first


Gold layer outcomes:
How many healthcare breaches are High, Medium, and Low risk?
Which breach types are most common?
Which breach types affect the most individuals?
Which months have more breach activity?
Which states report more healthcare breaches?
Which cases are the highest risk?
Which systems are commonly breached, such as network servers, email, EMR, paper/films?
